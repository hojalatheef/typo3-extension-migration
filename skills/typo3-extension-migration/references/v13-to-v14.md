# TYPO3 v13 → v14: extension migration cards

> Target platform: PHP 8.2–8.5, composer constraint `typo3/cms-core: ^14.3` (14.3 is the LTS, released 2026-04-21; dual support: `^13.4 || ^14.3`), Fluid standalone 5.x. A valid `composer.json` (`type: typo3-cms-extension`, `extra.typo3/cms.extension-key`) is mandatory even in classic mode. `ext_emconf.php` is deprecated since 14.2, and `ext_tables.php` since 14.3.
> Order of attack:
> 1. Finish the v13.4 deprecation log first. Every v13 deprecation (TSFE, `list_type`, StandaloneView, `renderStatic`, Extbase HashService, `addPageTSConfig`, `INCLUDE_TYPOSCRIPT`) is a fatal error or silent no-op in v14.0.
> 2. Fix `composer.json` (required in classic mode; add `extra.typo3/cms.version` and `Package.providesPackages` for v15 readiness), then bump constraints and run Rector `Typo3LevelSetList::UP_TO_TYPO3_14` plus Fractor.
> 3. Fluid 5: typed ViewHelpers (`initializeArguments(): void`, `render(): <type>`), no `renderStatic`, no `registerTagAttribute`, no `_`-prefixed variables. This breaks rendering loudly, so fix it early.
> 4. Extbase: annotations → attributes (`TYPO3\CMS\Extbase\Attribute`), validators extend `AbstractValidator`, and parameter-level `#[Validate]`.
> 5. Security opt-ins: `#[AsAllowedCallable]` on every TypoScript/TSconfig `userFunc` target. Review persisted HMACs (SHA3-256 default).
> 6. Clean the TCA (`searchFields`, `is_static`, `maxDBListItems`, `ds_pointerField`, subtypes), then run the DB analyzer, and the upgrade wizards for plugins (list_type → CType).

## Platform and packaging

### PHP and TYPO3 constraints for v14
- **Status:** breaking in v14.0
- **Detect:** `'typo3' *=> *'1[0-3]\.[0-9.]+-1[0-3]\.|"typo3/cms-[a-z-]+": *"\^1[0-3]\.[0-9]+"`
- **Replace with:** Use `"php": "^8.2"` and `"typo3/cms-core": "^14.3"` (or `"^13.4 || ^14.3"` for a dual release). Use the same range in any remaining `ext_emconf.php` `depends.typo3`.
- **Automation:** manual

### composer.json required in classic mode; ext_emconf.php deprecated
- **Status:** breaking in v14.0 (composer.json); ext_emconf.php deprecated v14.2 (ignored in v15)
- **Detect:** `\$EM_CONF\[`
- **Replace with:** Every extension needs a `composer.json` with `"type": "typo3-cms-extension"` and `extra.typo3/cms.extension-key`. Without it, classic mode does not detect the extension at all. Before v15, add `extra.typo3/cms.version` (matching the git tag) and `extra.typo3/cms.Package.providesPackages` (`{}` when none) to stop the ext_emconf deprecation. Title and description come from composer.json. Keep `ext_emconf.php` only for TER tooling and older cores.
- **Automation:** Rector `RequireComposerJsonInClassicModeRector` (verify behavior)
- **Changelog:** Breaking-108310-RequireComposerJsonInClassicMode

```json
{
  "name": "vendor/my-ext",
  "type": "typo3-cms-extension",
  "require": { "php": "^8.2", "typo3/cms-core": "^13.4 || ^14.3" },
  "extra": { "typo3/cms": { "extension-key": "my_ext", "version": "3.0.0",
    "Package": { "providesPackages": {} } } }
}
```

- **Detect:** `addFieldsToUserSettings\(|TYPO3_USER_SETTINGS.]\[.columns|PageDoktypeRegistry::class\)->add\(`

### TypoScript/TSconfig callables require `#[AsAllowedCallable]`
- **Status:** breaking in v14.0
- **Detect:** `(userFunc|preUserFunc|postUserFunc|postUserFuncInt|renderFunc) *[=<]`
- **Replace with:** Add `#[\TYPO3\CMS\Core\Attribute\AsAllowedCallable]` to every PHP method or global function called this way: `USER`/`USER_INT` `userFunc`, stdWrap `preUserFunc`/`postUserFunc`, constant-comment user functions, and TSconfig suggest `renderFunc`. Wrap native PHP functions in your own function first. Without the attribute, the call throws `AllowedCallableException`. For dual v13/v14 code, the attribute class does not exist on v13; PHP ignores attributes whose class is missing until something reflects on them.
- **Automation:** manual
- **Changelog:** Breaking-108054-EnforceExplicitOpt-inForTypoScriptTSconfigCallables

### System resource URLs and `typo3conf/ext/` paths
- **Status:** breaking in v14.0; helper methods deprecated v14.0 (removed v15)

## Plugins and TCA

- **Status:** breaking in v14.0

### Strict ViewHelper typing
- **Status:** breaking in v14.0
